# RoomPulse
Hey! I'm planning to build **RoomPulse**, a physical desktop environment and focus companion using an ESP32.

It will have a TFT display showing temperature, humidity and ambient light readings, a rotary encoder for navigation, physical focus timer controls and an RGB status ring.

I'm planning to design a custom enclosure and build the electronics myself. I'm relatively new to hardware, so I'm keeping the first version achievable and will expand it as I go.

Would this be suitable as a main Fallen project? I'd also appreciate feedback on the proposed components and scope before submitting my BOM for funding.
